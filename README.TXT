keyboard/
- VolumeBinds.ahk - хоткеи для звука, использования плеера. Может отправлять команды в отдельные интерфейсы(плееры)
  | NumpadAdd, NumpadSub: +-5 к звуку
  | Numpad8, Numpad2: +-1 к звуку
  | Numpad7: мут-размут
  | Numpad4, Numpad6: переключение контента выбранного плеера
  | Ctrl + Numpad5: переключение плеера

- WindowInteraction.ahk - хоткеи для взаимодействия с окнами через клавиатуру
  | Alt + Enter: полноэкранный-неполноэкранный режимы
  | Alt + Arrows: изменение размера
  | Ctrl + Arrows: движение
